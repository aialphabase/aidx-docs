# AIDX 資料リポジトリ(aidx-docs)

AIDX(法人向けAI DX事業)のプロンプト・仕様書・運用資料の**作業層リポジトリ**です。
レビュー・改訂・AIへの読み込み(clone・一括取得)を目的としています。

- 完成品を「見せる」場所(顧客・経営層向け)は GitHub Pages 側: <https://aialphabase.github.io/ai-dx-roi-preview/projects/aidx/>(ROI診断ツール・図解)
- 本リポジトリはPages化しません。GitHub上でフォルダツリーとして扱います

## フォルダ構成

```
/
├── README.md                        … 本ファイル(入口)
├── 00_manifest.csv                  … 全成果物の一覧(版・状態・参照元)
├── 01_全体像/                       … 顧客向け説明資料・図解(表紙・議題図・タイムライン図・Slack共有文)
├── 02_PJ仕様_Claude_Cowork版/       … PJ-01〜05の本体プロンプト(最新版のみ)
├── 03_品質確認/                     … QA-0X 手動再監査プロンプト
├── 04_テスト仕様/                   … PJ-01再現性テスト仕様
├── 05_AI利用ルール/                 … AI利用ルール雛形・顧客向けマニュアル
├── 06_音声同意/                     … 音声データ取扱いと同意(顧客向け)
└── 07_v1.0参考資料/                 … 旧v1.0統合版(Cowork仕様移行前の経緯資料・内部参照用)
```

## 収録の方針

- 各資料は**最新版のみ**収録(2026-07-22時点: PJ-01はv0.3、PJ-02〜05はv0.2、他はmanifest参照)。旧版(superseded)はGitの履歴と元の引き継ぎパックで参照する
- 以下は本リポジトリに**収録しない**: 引き継ぎパックの00_README(アカウント運用の内部情報)、08_Notion連携メモ(社内メンバー実名・内部URLを含む)
- 顧客固有情報・認証情報・未公開契約情報は追加しない

## 更新の流れ(必須)

1. 作業ブランチを作成(`claude/内容` など)
2. 変更をコミットしてPull Requestを作成
3. **PMレビュー**(PRコメント)
4. **レビューミーティング**(資料共有後に別途設定)
5. 承認後にマージ

mainへの直接コミットは初期構築時を除き行いません。

## AIに読み込ませる場合

- リポジトリごとclone、またはCode > Download ZIPで一括取得し、フォルダごとAI(Claude Cowork等)に渡す
- 個別ファイルのコピーは不要(フォルダツリーのまま読み込ませる前提の配置)
