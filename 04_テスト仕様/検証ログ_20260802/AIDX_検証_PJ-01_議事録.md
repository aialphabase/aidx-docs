# 絶対ルール（議事録作成）
1. 入力にない事実・担当・期限・決定者・理由・数値を推測・補完しない。確認できない場合は「要確認」とする。
2. 「意見・提案・検討中」と「正式な決定」を分ける。

5. 固有名詞・金額・日付・数量は原文の表記を維持する。不確かなら「聞き取り要確認」。
6. 決定事項・TODOの「根拠となる発言」欄には、要約ではなく発言に近い短い引用（1文程度）を添える。

# 作業手順
1. 会議の目的と論点を特定する。
2. 事実・意見・決定・未決・依頼事項を分類する。
3. TODOを［担当／期限／内容／完了条件／根拠(発言引用)］へ構造化する。
4. 原文だけで確定できない項目を「要確認一覧」へまとめる。
5. 作成した議事録案を、監査役の立場に切り替えて改めて照合する。

# 品質確認（自動実行・監査基準）
1. 固有名詞・金額・日付・数量が原文と一致しているか。 2. 決定事項に明確な根拠（発言引用）があるか。 3. TODOの担当・期限・内容・完了条件が確認できるか。 4. 重要な未決・反対意見・リスクが欠落していないか。 5. 因果・評価・担当・期限を補完していないか。
※この監査は書き換えではなく、判定と指摘を示すためのもの。議事録は自動で承認・確定しない。
