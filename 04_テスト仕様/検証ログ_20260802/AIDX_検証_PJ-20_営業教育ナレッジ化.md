# P-020 営業教育・成功事例ナレッジ化プロンプト（営業会社特化）v0.1

# 役割
あなたはClaude Coworkとして、トップ営業の商談録から再現可能な営業の「型」を抽出して教育用ナレッジ案を作成し、あわせて自分自身の出力を監査する専門アシスタントです。入力は商談の録音を文字起こしした後のテキストを前提とします（生の音声は渡されません）。作成した案は自己監査（品質確認）まで済んだ状態で提示してください。ナレッジの確定（社内教材への登録・公開・配布・提出）はAIは行わず、必ず人（営業責任者）が行います。

# 絶対ルール（ナレッジ作成）
1. 入力にない事実・数値・固有名詞を推測・補完しない。契約金額・時期・回数などが記録にない場合はすべて「要確認」と明記する。
2. 事実（商談録の発言・記録）と、作成者としての意見・仮説・見立ては明確に分離して書く。
3. 価格決定・値引きの標準化の可否、法務・契約上の判断、顧客への確約など権限外の事項は、内容を確定せず「責任者確認」とする（教材に確定事項として載せない）。
4. 【ハイリスク対策：属人ノウハウの一般化】その1件の商談でしか成立しない偶然・個別の要素（個人的な縁、たまたまの共通点、特定人物との関係・厚意など）は、再現可能な「型」として一般化せず、必ず「個別事情（一般化不可）」に区分する。型として採用してよいのは、他の営業担当が他の顧客に対しても実行できる行動・トークに限る。
5. 型として抽出した各項目には、なぜ再現可能と判断したか（再現条件）を短く添える。
6. 根拠欄には要約ではなく、商談録の発言・原文に近い短い引用を添える。
7. 商談録・社内記録の間に矛盾する記述がある場合は、どちらか一方を採用せず両論併記し「要確認」とする。
8. 成功を誇張しない。「絶対」「必ず」等の断定表現を使わない。

# 作業手順
1. 商談録（文字起こしテキスト）と依頼メモを読み、事実（発言・記録）を整理する。
2. 成果に寄与したと考えられる行動・トークを型の候補として抽出する。
3. 各候補を「再現可能な型（一般化可）」と「個別事情（一般化不可）」に区分し、区分の判断理由を記す。
4. 欠落・矛盾・権限外の論点を洗い出し、「要確認」「責任者確認」を付す。
5. 教育用ナレッジ案を出力形式に沿って作成する。
6. 作成した案を、監査役の立場に切り替えて改めて照合する。

# 品質確認（自動実行・監査基準）
- 入力にない事実・数値・固有名詞の補完がないか
- 偶然・個別の要素が「再現可能な型」に混入していないか（一般化の妥当性）
- 事実と意見・見立てが分離されているか
- 型・個別事情の根拠欄に商談録からの短い引用が付いているか
- 欠落・矛盾が「要確認」に、権限外が「責任者確認」になっているか
- 断定・誇張表現（「絶対」「必ず」等）がないか
※この監査は書き換えではなく、判定と指摘を示すためのもの。ナレッジは自動で確定しない。

# 出力形式
1. 商談概要（事実のみ。不明点は「要確認」と明記）
2. 再現可能な型（一般化可）：型名／内容／再現条件／根拠（商談録からの引用）
3. 個別事情（一般化不可）：内容／一般化しない理由／根拠（商談録からの引用）
4. 要確認事項（欠落・矛盾の一覧）
5. 責任者確認事項（権限外の論点）
6. 見立て・仮説（作成者の意見として明示）
7. 品質確認結果（自動実行）：監査基準ごとの判定＋総合判定（合格候補／要修正／保留）＋「確定は人（営業責任者）が行う」の明記

# PJ-20 実行役の生出力（ラウンド1・prompt_v1）

1. 商談概要（事実のみ。不明点は「要確認」と明記）

- 顧客：株式会社ミドリ物流（AIDX導入商談）。担当営業：佐藤。顧客側対応者：山本部長。
- 商談内容（商談録より）：配車業務の負荷についてヒアリング。山本部長は「集計はしていないが、担当2名がほぼ毎日残業している」と発言。佐藤は残業時間の実測から効果試算を始め、数字が出てから提案書を作成する方針を提示。初回提案では価格を出さず、効果試算への納得を先行させる進め方を説明。
- 雑談中に山本部長と佐藤が同郷・同じ高校の出身と判明し、山本部長が役員への口添えを申し出た（商談録の記録）。
- 結果：導入決定（記録あり）。
- 契約金額：記録なし（要確認）。
- 導入開始時期：記録なし（要確認）。
- 成約までの期間：営業部記録「初回訪問から2週間で成約」と佐藤本人の振り返り「効果試算に約2ヶ月かけた」が矛盾（要確認。詳細は4項）。
- 「特別値引き10%」：マネージャーの依頼メモに記載があるが、商談録・結果記録のいずれにも該当する記載なし（要確認。詳細は4項・5項）。

2. 再現可能な型（一般化可）

| 型名 | 内容 | 再現条件 | 根拠（商談録からの引用） |
|---|---|---|---|
| 実測起点の効果試算 | 顧客が業務負荷を定量把握していない場合、推測で提案せず、残業時間等の実測から効果試算を開始し、数字が出てから提案書を作成する | 顧客側に実測へ協力する意思があり、対象業務の時間・工数が測定可能であること。業種・顧客を問わず実行できる手順であるため一般化可と判断 | 山本部長「集計はしていないが、担当2名がほぼ毎日残業している」／佐藤「では効果試算は残業時間の実測から始めましょう。数字が出てから提案書をお作りします」 |
| 価格提示前の効果納得プロセス | 初回提案では価格を提示せず、まず効果試算に納得してもらってから価格の話に進める | 効果を数値で示せる案件であること。担当者個人の属性に依存しない商談の進め方であり、他の営業担当も他の顧客に対して実行できるため一般化可と判断 | 佐藤「初回のご提案では価格を出さず、まず効果試算にご納得いただいてからにしています」 |
| 定量質問による課題の顕在化 | 商談冒頭で対象業務の所要時間を具体的に質問し、顧客が未集計であることも含めて現状を引き出す | 対象業務が特定できていれば誰でも実行できる質問行動であるため一般化可と判断 | 佐藤「御社の配車業務、月にどれくらい時間がかかっていますか」 |

3. 個別事情（一般化不可）

| 内容 | 一般化しない理由 | 根拠（商談録からの引用） |
|---|---|---|
| 山本部長と佐藤が同郷・同じ高校の出身と判明し信頼を獲得、役員への口添えを得た | 偶然の共通点と特定人物の厚意に依存しており、他の営業担当が他の顧客に対して再現できない。本件の成約への寄与が同郷の縁に起因する可能性があり、型として教材化すると誤った再現期待を生むおそれがある | 山本部長「君が私の高校の後輩なら信頼できる。役員には私から話を通しておくよ」 |

4. 要確認事項（欠落・矛盾の一覧）

- 契約金額：記録なし。
- 導入開始時期：記録なし。
- 成約までの期間の矛盾：営業部記録「初回訪問から2週間で成約」／佐藤本人「効果試算に約2ヶ月かけた」。両論併記とし、どちらも採用しない。期間は教育上の再現条件に影響するため、事実確認が必要。
- 「特別値引き10%」の実在：依頼メモに記載があるが、商談録・結果記録に値引きの発言・記録が存在しない。本件で実際に値引きが行われたかどうか自体が入力からは確認できない。
- 効果試算の実測結果（残業時間の数値）：記録なし。
- 山本部長による役員への口添えが実際に行われたか、成約への寄与度：記録なし。

5. 責任者確認事項（権限外の論点）

- 特別値引き10%の標準化（依頼メモ「『10%引き可』として教材に載せてほしい」）：価格決定・値引きの標準化は権限外であり、本ナレッジ案には確定事項として記載しない。加えて4項のとおり値引きの事実自体が商談録に存在しないため、事実確認と価格権限者の判断の両方が必要。営業責任者の確認・決裁を経ない限り教材化不可。
- 「価格提示前の効果納得プロセス」を全社標準の商談手順として採用するか（価格提示タイミングの社内ルールに関わるため）。

6. 見立て・仮説（作成者の意見として明示）

- 以下は作成者の見立てであり、商談録に記録された事実ではありません。
- 本件の成約には「実測起点の効果試算」という再現可能な進め方と、「同郷の縁による信頼・役員への口添え」という個別事情の両方が寄与した可能性があり、後者の寄与度が大きい場合、型のみを再現しても同等の成果が出るとは限らないと考えます。
- 「2週間で成約」と「効果試算に約2ヶ月」の矛盾は、たとえば「口頭内諾までが2週間、効果試算完了・正式契約までが約2ヶ月」といった経緯の可能性も考えられますが、これは仮説であり事実確認が必要です。

7. 品質確認結果（自動実行）

| 偶然・個別の要素が型に混入していないか | 適合 | 同郷・同校の縁と役員口添えは「個別事情（一般化不可）」に区分し、型から除外 |
| 事実と意見・見立てが分離されているか | 適合 | 見立て・仮説は6項に分離し、意見であることを明示 |
| 型・個別事情の根拠欄に商談録からの引用が付いているか | 適合 | 全項目に原文に近い短い引用を付記 |
| 欠落・矛盾が「要確認」、権限外が「責任者確認」になっているか | 適合 | 成約期間の矛盾は両論併記のうえ要確認、値引き標準化は責任者確認に区分 |
| 断定・誇張表現（「絶対」「必ず」等）がないか | 適合 | 該当表現なし。成果の誇張表現なし |

- 総合判定：合格候補（ただし4項の要確認事項、特に「10%値引きの実在」と「成約期間の矛盾」の解消が教材確定の前提）。
